# HotelGenie — Telegram Mini App для подбора отелей с ИИ

Учебный проект (курсовая работа). Telegram Mini App, в котором
пользователь описывает желаемый отель обычными словами, а искусственный
интеллект разбирает запрос и подбирает подходящие варианты.

## Возможности

- **Умный поиск на естественном языке** — «отель в Сочи у моря на двоих
  до 6000 ₽ с бассейном» превращается ИИ в структурированные критерии.
- **Рекомендации ИИ** — короткий совет, на что обратить внимание.
- **Точные фильтры** — город, цена, звёзды, близость к морю.
- **Избранное и история** — сохраняются по идентификатору пользователя
  Telegram (с проверкой подписи initData).
- **Резервный режим** — при отсутствии ключа ИИ работает разбор на
  правилах, приложение остаётся полностью функциональным.

## Архитектура

```
frontend/  — Mini App (HTML/CSS/JS + Telegram WebApp SDK)
backend/   — REST API на FastAPI, БД SQLite, ИИ-сервис
bot/       — бот-лаунчер на aiogram (кнопка запуска Mini App)
```

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните значения
   (минимально для локального теста можно оставить пустыми —
   приложение откроется в браузере в гостевом режиме).

3. Запустите бэкенд (он же раздаёт фронтенд):
   ```bash
   uvicorn backend.main:app --reload
   ```
   Откройте http://localhost:8000 в браузере для проверки интерфейса.

4. Для работы внутри Telegram поднимите HTTPS-туннель и укажите его
   адрес в `WEBAPP_URL`, затем запустите бота:
   ```bash
   python -m bot.bot
   ```
   В Telegram отправьте боту `/start` и нажмите кнопку «Открыть HotelGenie».

## Технологии

Python 3.11, FastAPI, aiosqlite, httpx, aiogram 3, Telegram Mini Apps,
OpenAI-совместимый API языковой модели.
